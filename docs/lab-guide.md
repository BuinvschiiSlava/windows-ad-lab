# Пошаговая лабораторная работа

## Этап 1 Подготовка хоста

1. Включите Hyper-V и перезагрузите компьютер.
2. Скачайте официальные ISO Windows Server и Windows 10 или 11.
3. Создайте копию `config/lab.example.psd1` с именем `config/lab.psd1`.
4. Выполните `Test-LabPrerequisites.ps1`.
5. Проверьте свободную подсеть и выполните `New-LabNetwork.ps1 -WhatIf`.

## Этап 2 Установка VM

Создайте `DC01` и `CLIENT01`, установите ОС, Windows updates и Hyper-V integration services. Не используйте пароли от реальных учётных записей. Создайте checkpoint `clean-install` для каждой VM.

## Этап 3 AD DS

Подготовьте статический адрес DC01, установите новый лес и дождитесь перезагрузки. Убедитесь, что `Get-ADDomain` возвращает `corp.lab`, а `Resolve-DnsName dc01.corp.lab` — адрес `192.168.56.10`.

## Этап 4 Каталог и доступ

Создайте OU, группы и тестовые учётные записи. Убедитесь, что права на `Company` наследуются от групп. Не назначайте права напрямую пользователям.

## Этап 5 Клиент

CLIENT01 должен использовать DC01 как DNS. После domain join проверьте `whoami`, `nltest /dsgetdc:corp.lab`, `gpupdate /force` и `gpresult /r`.

## Этап 6 Zabbix

Запустите Docker Compose, смените стандартный пароль администратора Zabbix, установите Agent 2 и добавьте DC01/CLIENT01 с шаблоном Windows by Zabbix agent. Создайте триггеры для недоступности агента, заполнения диска и высокой загрузки CPU.

## Этап 7 Восстановление

Создайте checkpoints, измените GPO или ACL, зафиксируйте симптомы и восстановите корректную конфигурацию. Checkpoint используется только для учебной VM; для реального AD он не заменяет system state backup.
