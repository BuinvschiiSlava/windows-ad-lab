# Архитектура лаборатории

## Граница стенда

Лаборатория использует внутренний Hyper-V switch. Виртуальные машины получают доступ в интернет через NAT хоста, но не публикуют доменные службы во внешнюю сеть. Контроллер домена имеет статический адрес `192.168.56.10`, клиент получает адрес по DHCP.

## Роли DC01

- AD DS хранит доменные объекты и выполняет аутентификацию.
- DNS хранит доменную зону `corp.lab`; доменные клиенты используют только DC01 как DNS.
- DHCP выдаёт адреса клиентам и передаёт адрес доменного DNS.
- GPO задаёт воспроизводимую политику рабочих станций.
- SMB демонстрирует назначение прав через глобальные группы.

## Модель каталогов

```text
corp.lab
├── OU=Users
├── OU=Computers
├── OU=Servers
├── OU=Groups
└── OU=Service Accounts
```

Доступ назначается группам `GG-Shared-Read` и `GG-Shared-Modify`. Учётные записи включаются в группы, а ACL файловой системы и SMB share ссылаются только на группы.

## Мониторинг

Zabbix работает в трёх контейнерах: PostgreSQL, Zabbix Server и Zabbix Web. Интерфейс и серверный порт привязаны к localhost. Windows Agent 2 устанавливается в виртуальные машины только из заранее скачанного MSI с обязательной проверкой SHA-256.
