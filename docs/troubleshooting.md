# Диагностика проблем

## Клиент не входит в домен

1. Проверьте, что DNS клиента указывает только на DC01.
2. Выполните `Resolve-DnsName _ldap._tcp.dc._msdcs.corp.lab -Type SRV`.
3. Сравните время клиента и DC01: Kerberos чувствителен к рассинхронизации.
4. Проверьте порты 53, 88, 389, 445 и 464.
5. Изучите журналы `System`, `DNS Server` и `Directory Service`.

## Клиент не получает DHCP

1. Убедитесь, что DHCP Server авторизован в AD.
2. Проверьте активность scope и наличие свободных адресов.
3. Убедитесь, что CLIENT01 и DC01 подключены к одному Hyper-V switch.
4. Выполните `ipconfig /release` и `ipconfig /renew`.

## Нет доступа к общей папке

Проверьте одновременно share permissions и NTFS ACL. Итоговый доступ равен наиболее строгому пересечению этих разрешений. После изменения групп выполните выход и повторный вход, чтобы обновить Kerberos token пользователя.

## Zabbix не видит агент

1. Проверьте службу `Zabbix Agent 2`.
2. Проверьте Windows Firewall для TCP 10050 внутри лабораторной подсети.
3. Убедитесь, что в конфигурации агента указан правильный Zabbix Server.
4. Из контейнера Zabbix Server проверьте маршрут до адреса VM.
5. Сверьте имя host в Zabbix с параметром `Hostname` агента.
